# 📓 Notebooks Directory

This directory contains the core analytical work of the project, including individual country EDAs and the final cross-country comparison.

## 📁 Analytical Workflow

1. **Per-Country EDA**:
   - `ethiopia_eda.ipynb` (Master Template)
   - `kenya_eda.ipynb`, `sudan_eda.ipynb`, etc.
   - *Goal:* Individual data cleaning, profiling, and initial insight generation.

2. **Comparative Analysis**:
   - `compare_countries.ipynb`
   - *Goal:* Synthesizing all 5 datasets to identify relative vulnerabilities and COP32 recommendations.

---

## 🚀 How to Run
Ensure your virtual environment is activated and dependencies are installed:
```bash
# From the project root
pip install -r requirements.txt
jupyter notebook
```
