# 📊 Data Directory

This directory stores the climate datasets used in this project. 

> [!IMPORTANT]
> Raw and processed CSV files are excluded from version control (see `.gitignore`) to keep the repository lightweight. Only documentation and visualization images are tracked.

## 📁 Subdirectories

- `raw/`: Original NASA POWER datasets (Daily 2015-2026).
- `processed/`: Cleaned datasets ready for analysis.
- `images/`: Exported visualization plots (PNG format) for use in reports.

## 📝 Data Source
All data is sourced from the **NASA POWER (Prediction Of Worldwide Energy Resources)** project, focusing on near-surface temperature, precipitation, humidity, and wind speed.
